# BancoBanQuito — Core Bancario

Backend principal del banco. Gestiona clientes (naturales y jurídicos), cuentas, transacciones, sucursales y feriados. Expone una API REST que es consumida tanto por la intranet del banco como por el servicio de pagos masivos (Switch).

Desarrollado en **Java** con **Spring Boot**. Usa **MariaDB** como base de datos.
